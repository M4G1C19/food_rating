FoodRate — Веб-приложение «Рейтинг кулинарных блюд»

Учебный проект на **FastAPI**, представляющий собой лендинг с рейтингом блюд. Реализована система авторизации с разграничением прав доступа, сессии с таймаутом, логирование действий и загрузка изображений.

 Основной функционал

*   **Три роли пользователей:**
    *   **Неавторизованный гость:** может просматривать главную страницу.
    *   **Читатель (reader):** может просматривать главную страницу и свой профиль. Не имеет доступа к панели управления.
    *   **Администратор (admin):** полный доступ. Может добавлять и удалять блюда, а также просматривать свой профиль.
*   **Безопасность:** пароли хранятся в базе (CSV) в виде хеша (SHA-256).
*   **Сессии:** время жизни сессии пользователя составляет 5 минут (300 секунд).
*   **Логирование:** все действия пользователей (вход, регистрация, переходы) записываются в файл `logs.csv`.
*   **Интерфейс:** адаптивный и современный дизайн, реализованный на чистом CSS и JS (с функцией живого поиска по блюдам).

Технологии

*   **Язык:** Python 
*   **Фреймворк:** FastAPI, Starlette
*   **Фронтенд:** HTML, CSS, JavaScript
*   **Хранение данных:** Pandas (CSV-файлы)
